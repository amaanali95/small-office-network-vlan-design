# Small Office Network Design and Implementation Using VLANs

## Project Overview
This project demonstrates the design and configuration of a small office network using Cisco Packet Tracer. The network uses VLANs to separate departments and improve network organization, security, and management.

## Objectives
- Design a small office network topology.
- Create and configure VLANs.
- Configure trunk links between network devices.
- Implement inter-VLAN routing.
- Configure IP addressing and DHCP.
- Practice SSH configuration, ACLs, and network troubleshooting.

## Technologies Used
- Cisco Packet Tracer
- Cisco Router and Switch
- VLANs and Trunking
- Inter-VLAN Routing
- IPv4 Addressing and Subnetting
- DHCP
- SSH
- Access Control Lists (ACLs)

## Network Configuration

| VLAN | Department | Network Address | Default Gateway |
|---|---|---|---|
| 10 | Department 1 | 192.168.10.0/24 | 192.168.10.1 |
| 20 | Department 2 | 192.168.20.0/24 | 192.168.20.1 |
| 30 | Department 3 | 192.168.30.0/24 | 192.168.30.1 |
| 40 | Department 4 | 192.168.40.0/24 | 192.168.40.1 |

## Implementation Steps
1. Designed the network topology in Cisco Packet Tracer.
2. Created VLANs for different departments.
3. Configured switch access ports and trunk links.
4. Configured router subinterfaces for inter-VLAN routing.
5. Planned IP addressing and DHCP configuration.
6. Tested connectivity and troubleshot network issues.
